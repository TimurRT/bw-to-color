# 🎨 BW-to-Color — Colorization GAN
Проект для автоматической колоризации чёрно-белых изображений с использованием GAN (Pix2Pix-style) с предобученным ResNet18-энкодером. 
Интеграция с ClearML для отслеживания экспериментов, хранения датасетов и моделей, удалённого обучения на Google Colab.

## Как работает система

Проект решает задачу автоматической колоризации чёрно-белых изображений с помощью генеративно-состязательной сети (GAN).

**Данные.** Используется датасет COCO 2017 Train (20 тысяч цветных изображений). При обучении изображения конвертируются в оттенки серого и подаются на вход модели. Аугментации (повороты, отражения, цветовые искажения) применяются на лету для увеличения разнообразия.

**Модель.** Генератор построен по архитектуре U-Net: энкодер — предобученный ResNet18, который уже умеет выделять формы и объекты; декодер — новые слои, которые учатся восстанавливать цвет. Дискриминатор PatchGAN оценивает реалистичность раскрашенных участков 70×70 пикселей. Генератор учится обманывать дискриминатор, одновременно минимизируя L1-ошибку между предсказанным и настоящим цветом.

**Обучение.** Запускается локально или через ClearML Agent на удалённой машине (включая Google Colab с бесплатным GPU). ClearML сохраняет все метрики, чекпоинты и финальную модель. Гиперпараметры можно менять через веб-интерфейс без правки кода.

**Тестирование.** Готовую модель можно протестировать через скрипт, который загружает изображения из папки и выводит сетку «до/после», либо через веб-приложение на Flask с удобным интерфейсом: загрузил фото, нажал кнопку — получил результат справа от оригинала.

**Хранение.** Датасет и обученные модели хранятся в ClearML и не занимают место на локальном компьютере. Веб-приложение работает полностью оффлайн, модель загружается из локальной папки.

## Установка

1. Клонирование репозитория:
```bash
git clone <url-репозитория>
cd bw-to-color
```

2. Установка зависимостей через uv:
```bash
uv sync
```

3. Настройка ClearML
```bash
clearml-init
```

## Подготовка датасета

```bash
uv run python scripts/upload_dataset.py
```

## Обучение модели

Локальный запуск:
```bash
uv run python main.py --epochs 8 --batch_size 4
```

Аргументы командной строки:

--epochs — количество эпох (по умолчанию 50)
--batch_size — размер батча (по умолчанию 16)
--lr — learning rate (по умолчанию 0.0002)
--image_size — размер изображений (по умолчанию 256)
--lambda_l1 — вес L1-лосса (по умолчанию 100.0)
--num_workers — количество воркеров DataLoader (по умолчанию 4)
--dataset_limit — максимальное количество изображений (0 = все)

Для запуска агента через Google Colab:
```python
!pip install clearml clearml-agent

!clearml-agent daemon --queue default
```

## Тестирование модели
Локально модель можно проверить, поместив несколько изображений в папку test_images и запустив скрипт test_local.py:
```python
uv run python scripts/test_local.py
```

Модель должна лежать в models/generator_final.pth

Для тестирования через веб-приложение, необходимо запустить сервер:
```python
uv run python webapp/server.py
```

Затем открыть в браузере: http://127.0.0.1:5000
В верхней панели выбрать модель из выпадающего списка, нажать «Выбрать фото» и загрузить цветное изображение, нажать «Раскрасить».
Слева отображается оригинал, справа — результат колоризации
Модели для выбора берутся из папки models/. Достаточно положить туда .pth файл, и он появится в списке.

## Архитектура модели
Генератор: U-Net с предобученным ResNet18 в качестве энкодера
Дискриминатор: PatchGAN (70x70)
Функция потерь: GAN loss (BCEWithLogits) + L1 loss
Аугментации: random horizontal flip, rotation (±15°), color jitter

## Результаты
Поставленная цель была достигнута, модель действительно генерирует раскрашенные изображения, часто верно определяя цвета, в особенности хорошо справляясь с зеленью и деревьями, а также небом. При этом модель отличает траву от воды, верно генерируя океан синим, что означает что успех модели в идентификации земли/неба зависит не только от позиции пикселей на изображении.
